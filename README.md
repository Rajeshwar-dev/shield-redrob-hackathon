## Project Overview
This repository contains our submission for the **Redrob Intelligent Candidate Discovery & Ranking Challenge**.

We developed a Python-based candidate ranking engine that analyzes candidate skills, experience, career history, and behavioral signals to identify and rank the most suitable candidates for a Senior AI Engineer role.

## Approach
- Job description analysis
- Skill and experience matching
- Behavioral signal evaluation
- Weighted candidate scoring
- Top 100 candidate ranking generation

## Technology Stack
- Python
- JSONL Processing
- CSV Generation
- Rule-Based Ranking Engine

## Repository Contents
- `final_ranker.py` – Main ranking algorithm
- `submission.csv` – Final ranked candidate output
- `Shield_Redrob_Hackathon_Deck.pdf` – Project presentation
